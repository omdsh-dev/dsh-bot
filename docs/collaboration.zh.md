# 邀请 Bot 一起讨论

适用于主包 0.13.0、飞书连接器 0.7.0、如流连接器 0.8.0。发布、安装和验收状态见[完成记录](feature-completion.md)。

## 页面怎么用

在聊天顶部点「＋邀请 Bot」，直接查看 Bot 的名称、能力和可用状态。输入框的 `@` 列表也可以打开邀请窗口。选择 Bot 后，填写或修改共享背景；需要携带原对话内容时，勾选要分享的已完成消息及其附件，再点「邀请并继续」。Bot 推荐的协作建议也提供同一个确认入口。

- 从私聊邀请：创建关联群聊，保留原私聊及未发送草稿；原 Bot 和受邀 Bot 使用新的群聊 Session。点击「原对话」可回到私聊。
- 从群聊邀请：加入当前群，保留现有成员的 Session 和未发送草稿。新成员可以读取群里的公开上下文；这不是只对它展示所选摘要的私密旁路。
- 原 Bot 继续负责协调，新 Bot 先回答本次共享背景。忙碌群聊把新回复排入原有队列。

共享背景最多 8000 字，最多选择 20 条已完成消息，所选原文合计最多 16000 字；最多携带 8 个附件、合计 20 MB。窗口提供最近 40 条消息供选择。未选中的私聊记录、未发送草稿和原 Session 不会复制到群里。已有的记忆权限仍按原有作用域规则生效，邀请不会复制或提升私有记忆权限。

## 在飞书、如流里怎么用

可以向当前 Bot 说：「请找一个擅长代码审查的 Bot 一起讨论，先让我确认要共享的背景。」Bot 查找可邀请的能力 Bot，给出名称和完整背景后，等待用户在后续消息确认；确认后才调用平台邀请接口。也可以打开对应 Web 聊天，在邀请窗口检查和修改。

IM 中发现与确认邀请仅允许当前聊天的已验证管理员，并要求该用户同时拥有目标 Bot 的管理权限。飞书不同应用的 Open ID 不直接比较；需使用同一条事件的各应用身份记录，或部署者配置的明确身份关联。姓名相同不会授予权限。原生执行审批继续在 DSH 页面完成。

已有 IM 群只邀请机器人。私聊升级为群需要一个明确群主：IM 确认为当前管理员；页面上由用户显式填写或选择。如流群主必须在建群邀请白名单内，不推断群主，不额外添加真人同事。飞书的群主 Open ID 属于发起建群的应用。

两个 Bot 都必须已在同一平台绑定、启用并连接。飞书统一授权包含 `im:chat.members:write_only`；已有应用需再次完成统一授权及平台要求的发布或组织审批。软件不能代替平台管理员授予权限。

## 失败和恢复

每次邀请保存固定请求和结果。平台超时、审批未完成或返回不确定结果时，保留原请求，点击「继续本次邀请」。系统重新核验群成员；只有所有机器人实际在群内，才把邀请标记为完成。已知群不会再次创建，已在群的 Bot 不重复添加。进群期间保留已有连接和共享消息队列。

重新加载页面仍可从原聊天继续未完成邀请。若绑定、身份权限或白名单不符合要求，先修正配置再重试。连接器版本过旧时页面给出升级说明。

这一版实现群内协作。离开群聊的临时一次性求助、自动拉入未绑定 Bot，以及不经用户确认的自动邀请不在本版范围内。
