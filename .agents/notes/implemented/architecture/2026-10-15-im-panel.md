# Unified IM configuration panel

The Bot sidebar exposes one IM connections entry. IMPanel owns the common heading, return action and accessible Feishu/InfoFlow tabs. Each provider owns its existing Bot selection, configuration editor and group controls. Both provider sections remain mounted while the panel is open so a platform switch retains drafts, selected Bots and active registration views. Closing the panel disposes its polling effects as before. The panel does not change any Remote operation, credentials, allowlists or transport ownership.

Existing UI acceptance tests now reach configuration through the shared entry, check visible tab selection and keyboard navigation, preserve an unsaved Feishu credential across a platform switch, and exercise the existing per-Bot save/registration/group actions. Build verification and a browser check on the installed local DSH cover the rendered entry and both provider sections.
